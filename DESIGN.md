# FarmOS visual direction

The full-screen map shows the same aerial parcel from an entire-plot camera or a tractor follow camera. Marker color and the handoff countdown identify the simulation state. A separate tab embeds the official AgOpenWeb view using the local relay. Activity floats in the upper corner. Ask FarmOS floats in the lower corner and contains the assignment form.

| Reference | Observed on the captured homepage | FarmOS adaptation |
| --- | --- | --- |
| [Landdding](https://landdding.com/) | Large previews with compact captions | Guidance occupies the largest panel |
| [Motion](https://motionin.design/) | Rounded surfaces frame interactive previews | Live guidance and a state change show the handoff |
| [posts.design](https://posts.design/) | High-contrast, modular tiles | The dark decision card uses lime for an active recovery |

FarmOS uses DM Sans for controls, Instrument Sans for headings, and IBM Plex Mono for coordinates and timing.
